# Realistic background images (drop your scene photos here)

The Speaking screen shows a realistic scene behind the avatar when the matching
image exists. If missing, the app falls back to the themed gradient backdrop.

## File names (one per scenario key)
`coffee.jpg`, `airport.jpg`, `restaurant.jpg`, `hotel.jpg`, `interview.jpg`,
`doctor.jpg`, `ielts.jpg`, `shopping.jpg`, and `default.jpg` (fallback).

## Image spec
- **JPG**, portrait-ish, ~**1080×1920** (covers the phone screen, `BoxFit.cover`).
- A real/3D-rendered scene that matches the scenario (e.g. a cozy coffee shop
  interior, an airport check-in hall, a clinic room).
- A dark scrim is applied automatically over the photo so the glass panels and
  text stay readable — pick scenes that look good slightly darkened.
- Generate with your image tool, matching the avatar's environment.
